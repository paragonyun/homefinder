# HomeScope PRD

## 제품 정의

HomeScope는 사용자가 관심 동네와 아파트를 등록하면 공공데이터와 공식 API 기반 정보를 정리하고, 임장 기록과 개인 판단을 함께 남길 수 있게 하는 개인용 부동산 리서치 보드입니다.

목표는 매수/매도 추천이 아니라 후보 단지를 체계적으로 비교하고 판단 근거를 보존하는 것입니다.

## 대상 사용자

- 1차 사용자는 본인입니다.
- 향후 가족, 지인 등 최대 10명 내외까지 고려합니다.
- 부동산 전문가가 아니라 여러 사이트를 오가며 정보를 모으는 일반 사용자를 기준으로 합니다.

## 핵심 가치

1. 관심 단지를 한곳에 모읍니다.
2. 실거래가 추이를 자동으로 봅니다.
3. 단지 기본정보를 자동으로 봅니다.
4. 여의도/강남 접근성처럼 개인에게 중요한 기준을 봅니다.
5. 임장 후기를 누적합니다.
6. 여러 단지를 비교합니다.
7. 나중에 왜 관심/보류/제외했는지 복기합니다.

## 제품 원칙

- 공식 데이터 우선: 공공데이터포털, 정부/공공기관 API, 합법적으로 이용 가능한 지도/주소/교통 API를 우선합니다.
- KB부동산 자동 수집 제외: KB시세, AI시세, 예측시세는 MVP에서 자동 수집하지 않고 참고 링크와 확인 필요 상태만 둡니다.
- 수기 입력 최소화: 단지명 또는 주소 입력 후 가능한 매핑값은 자동 수집하되, 임장 후기와 정성 메모는 사용자가 직접 입력합니다.
- 판단 보조: 화면 문구는 추천보다 관심 후보, 관찰 후보, 임장 필요, 보류, 제외, 추가 확인 필요 같은 표현을 사용합니다.
- 데이터 신뢰도 표시: 주요 값은 `source_name`, `source_ref`, `fetched_at`, `confidence_level`을 함께 다룹니다.

## MVP 1: 관심 단지 리서치 보드

포함:

- Supabase Auth 기반 기본 로그인 방향
- 관심 동네 CRUD
- 관심 아파트 CRUD
- 단지명/주소 기반 등록 flow
- 주소에서 좌표 변환 구조
- 국토부 아파트 매매 실거래가 API adapter 구조
- 평형대별 실거래가 테이블과 가격 추이 차트 자리
- K-apt 공동주택 기본정보 adapter 구조
- 단지 상세 페이지 구조
- 데이터 출처/갱신일 표시 구조
- 임장 메모 기본 CRUD 구조
- 단지 상태: 후보, 관심, 임장 예정, 임장 완료, 보류, 제외

제외:

- 자동 매수/매도 판단
- KB부동산 자동 수집
- 복잡한 AI 분석
- 대출 시뮬레이션
- 고급 지도 기능
- 상업용 권한체계

## MVP 2: 입지/접근성/학군 분석

- 주변 초/중/고 검색
- 학교 기본정보 표시
- 단지에서 학교까지 거리 계산
- 여의도역/강남역 대중교통 소요시간
- 지도 위 단지와 학교 표시
- 목적지 커스텀 기능

## MVP 3: 의사결정 보드

- 단지별 점수화
- 가격 부담, 실거주, 접근성, 학군/생활권, 단지 체급, 리스크 점수
- 임장 점수 반영
- 관심/보류/제외 사유 정리
- 비교 리포트와 인쇄/PDF용 화면

AI 요약은 선택사항입니다. 우선 규칙 기반 요약으로 시작하고, 나중에 LLM을 붙일 수 있도록 구조만 열어둡니다.
